# PAO facts v4 — completing 00–99

## Summary

- New notes: **45** across **35** previously blank numbers.
- Role split: **32 Person / 6 Action / 7 Object**.
- Coverage after v3 + v4: **126 notes across all 100 numbers**
  (95 Person, 15 Action, 16 Object).
- All 45 notes are **strong**: each is an ordinal, date, title, record, or
  designation that can be checked directly against the cited page.
- No note is longer than 90 characters, lowercased, and has no trailing period.

## What changed in the vocabulary

Completing the library meant changing some words, not just adding notes. The
changes were chosen so that one number can carry several linked roles.

| n | Person | Action | Object | link |
|---|--------|--------|--------|------|
| 49 | Joe Montana | passing | football | 49ers, Super Bowl XLIX |
| 51 | Michel Mayor | discovering | planet | 51 Pegasi b |
| 66 | Nat King Cole | driving | highway | Route 66 |
| 68 | Rick Mears | racing | car | 68th Indy 500 |
| 69 | Buzz Aldrin | landing | moon | Apollo 11, 1969 |

The other new numbers use a solid single-role hook and keep their existing art.

### New object art

Five object words changed, so five sprites changed with them. Every sprite is
still 13 × 7 and uses the existing character set (`# ▒▓░ █ .-'"/\ _|()`).

- **49 football** — pointed oval with laces.
- **51 planet** — sphere with a ring and shaded bands.
- **66 highway** — road receding to a horizon with a centre line.
- **68 car** — side view with windows and two wheels.
- **69 moon** — full moon with craters and two stars.

Person and Action art is procedural and number-based, so no art files changed
for those roles.

### Grammar changes in `ACTION_LINK`

- `passing`, `discovering`, and `racing` are **direct** verbs
  (`passing a football`, `discovering a planet`, `racing a car`).
- `driving` and `landing` take **on** (`driving on a highway`,
  `landing on a moon`).
